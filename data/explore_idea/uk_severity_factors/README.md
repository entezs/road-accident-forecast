# uk_severity_factors

ข้อมูลของไอเดีย "ปัจจัยที่ทำให้อุบัติเหตุร้ายแรง" ที่ใช้ข้อมูลอังกฤษ (UK STATS19) แทนข้อมูลไทย

ไฟล์ทั้งหมดในโฟลเดอร์นี้สร้างจาก `notebooks/explore_idea/uk_severity_factors.ipynb` ถ้าไฟล์หายหรืออยากสร้างใหม่ ให้รัน notebook จากบนลงล่าง ใช้เวลาประมาณ 1–2 นาที (ไม่นับเวลาโหลดไฟล์ดิบครั้งแรก)

| โฟลเดอร์ | ไฟล์ | คืออะไร |
|---|---|---|
| `clean/` | `collisions_clean.csv` | ข้อมูลที่คลีนแล้ว หนึ่งแถวคืออุบัติเหตุ 1 ครั้ง (309,049 แถว) รวมข้อมูลจากตารางรถและผู้บาดเจ็บเป็นรายเหตุแล้ว |
| `features/` | `collisions_factors.csv` | ปัจจัยแบบ 0/1 จำนวน 35 ตัว กับเขตตำรวจ ปี คำตอบ `severe` และ `split` |
| `model/` | `factor_model.joblib` | Logistic Regression ที่ฝึกด้วยข้อมูลทุกปี |
| `results/` | `factor_table.csv` | ตารางคำตอบ: odds ratio ของแต่ละปัจจัย ชุดของปัจจัย (A = ข้อมูลไทยก็มี, B = ไทยไม่มี) ค่าของสองช่วงปี ช่วงความไม่แน่นอน และผลสรุป |

**ข้อมูลดิบ** อยู่ที่ `data/stats19/` (3 ไฟล์ รวมประมาณ 255 MB) ไม่ได้เก็บใน git เพราะใหญ่เกินไป notebook จะโหลดจากเว็บของ DfT ให้เองถ้ายังไม่มี

**เลือกเฉพาะเหตุที่บันทึกด้วยระบบใหม่ (`collision_injury_based = 1`):** ตำรวจอังกฤษแต่ละเขตบันทึกความรุนแรงคนละระบบ ระบบใหม่นับเหตุร้ายแรงมากกว่า จึงใช้ระบบเดียวเพื่อไม่ให้โมเดลเรียนรู้ความต่างของวิธีบันทึก

**ต่างจาก `severity_factors` อย่างไร:** โจทย์เดียวกัน แต่ข้อมูลอังกฤษมีความเร็วจำกัดของถนน ไฟถนน ผิวถนน ขนาดจักรยานยนต์ และอายุคนขับ ซึ่งข้อมูลไทยไม่มี และเก็บเฉพาะเหตุที่มีผู้บาดเจ็บ หัวข้อ 9.4 ของ notebook อ่านไฟล์ของ `severity_factors` เพื่อเทียบสองประเทศแบบยุติธรรม
