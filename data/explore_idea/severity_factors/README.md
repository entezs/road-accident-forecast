# severity_factors

ข้อมูลของไอเดีย "ถ้าอุบัติเหตุร้ายแรง ร้ายแรงเพราะปัจจัยอะไร"

ไฟล์ทั้งหมดในโฟลเดอร์นี้สร้างจาก `notebooks/explore_idea/severity_factors.ipynb` ถ้าไฟล์หายหรืออยากสร้างใหม่ ให้รัน notebook จากบนลงล่าง ใช้เวลาประมาณ 1 นาที

| โฟลเดอร์ | ไฟล์ | คืออะไร |
|---|---|---|
| `clean/` | `accidents_clean.csv` | ข้อมูลที่คลีนแล้ว หนึ่งแถวคืออุบัติเหตุ 1 ครั้ง (150,097 แถว) |
| `features/` | `accidents_factors.csv` | ปัจจัยแบบ 0/1 จำนวน 27 ตัว กับจังหวัด ประเภทถนน ปี คำตอบ `severe` และ `split` |
| `model/` | `factor_model.joblib` | Logistic Regression ที่ฝึกด้วยข้อมูลทุกปี |
| `results/` | `factor_table.csv` | ตารางคำตอบ: odds ratio ของแต่ละปัจจัย ค่าของสองช่วงปี ช่วงความไม่แน่นอน และผลสรุป |

**ข้อมูลดิบ** ไม่ได้คัดลอกมาไว้ที่นี่ notebook อ่านจาก `data/datagov/` โดยตรง (ปี 2020–2026)

**ต่างจาก `severity_map` อย่างไร:** ไอเดียนั้นทำนายว่าเหตุจะร้ายแรงไหมจากข้อมูลที่รู้ก่อนเกิดเหตุ ไอเดียนี้อธิบายว่าเหตุร้ายแรงเพราะปัจจัยอะไร จึงใช้ข้อมูลที่บรรยายตัวเหตุด้วย เช่น จำนวนรถแต่ละประเภทในเหตุ ลักษณะการชน และมูลเหตุสันนิษฐาน
